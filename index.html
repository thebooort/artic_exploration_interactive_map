Historical Expeditions

Arctic Routes

Historic expedition routes reconstructed from maps in books of the Royal Geographical Society, georeferenced using QGIS, and visualised on an interactive 3D globe built with HTML5 Canvas, JavaScript and WebGL. Each expedition has its own colour; select a name to explore its route.
